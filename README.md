## Descripción del problema

Este proyecto resuelve un problema sencillo de la vida real: **calcular el salario
semanal de un trabajador** a partir de dos datos: el pago por hora y la cantidad
de horas trabajadas durante la semana.

Para resolverlo se definió la función `calcular_salario_semanal(pago_por_hora,
horas_trabajadas)`, la cual multiplica ambos parámetros y devuelve el resultado
mediante `return`. Esta función se invoca desde el bloque principal del programa
(`if __name__ == "__main__":`), donde se muestra el resultado en consola con
`print()`.

## Archivo del proyecto

- `salario.py`: contiene la función y su llamada desde el bloque principal.

## Cómo ejecutar

\`\`\`bash
python3 salario.py
